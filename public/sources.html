SOURCES & IMPLEMENTATION NOTES

What this example shows—and what it doesn’t.

This project follows one sentence through a small teaching implementation of a decoder-only transformer. The sources below establish background and reference configurations; they do not imply that this project has trained or run a pretrained model.

The teaching model

The code is GPT-2 Small–style: 12 blocks, width 768, 12 attention heads, a 50,257-entry GPT-2 vocabulary, and an intentionally shorter 256-token context. It uses learned token and absolute-position embeddings, causal self-attention, pre-LayerNorm sublayers, residual additions, GELU, and a final LayerNorm.

No pretrained weights are loaded. Parameters are randomly initialised. The attention scores, embedding bars, generation logits and probabilities, candidate continuations, and training curve are illustrative or editorial examples—not model outputs.

The code differs from released GPT-2 Small in some choices, including an untied, bias-free output projection. The 256-token context also differs from GPT-2 Small’s commonly documented 1,024 positions. These are implementation details, not requirements of transformers generally.

Reproducible examples

The recorded token IDs and pieces are in tokenizer_demo.json. The three-candidate temperature example is calculated from fixed toy logits [2, 1, 0] and recorded in generation_demo.json. Both artifacts include provenance; neither contains checkpoint inference.

The complete teaching implementation is available in the source browser. The detailed educational content audit documents additional simplifications and accessibility notes.
